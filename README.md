# EmotionSense – Automated Emotion Detection from Text

## Project Description
EmotionSense is a deep learning based system that automatically detects human emotions from textual comments and feedback. It uses a BERT transformer model to classify emotions such as sadness, anger, love, surprise, fear, and joy.

The project also provides a user-friendly web interface using Streamlit for real-time emotion prediction.

---

## Features
- Emotion detection from text input
- BERT transformer-based classification model
- High accuracy (95.7%)
- Streamlit web interface
- Complete testing documents (test cases, scenarios, design, report)

---

## Emotions Supported
- Sadness
- Anger
- Love
- Surprise
- Fear
- Joy
